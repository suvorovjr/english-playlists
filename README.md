# English по плейлистам

Личное мобильное веб-приложение (PWA) для изучения английского по видеокурсу
«Английский язык по плейлистам» (English Galaxy, уровни A1–C1): видеоурок + много упражнений
в стиле Duolingo на закрепление.

## Что внутри
- **Видео** урока прямо в приложении + конспект, слова и фразы с озвучкой.
- **5 уровней тренировки** на каждый урок — от выбора вариантов и плиток до перевода с клавиатуры,
  диктанта и говорения. Ошибки возвращаются в конец тренировки.
- **Интервальное повторение**: каждая фраза, слово и правило имеет «силу»; приложение
  напоминает повторить то, что пора повторить, и тренирует слабые места.
- **Говорение**: распознавание речи браузера (Chrome на Android, Safari на iOS).
- Работает офлайн (кроме видео), прогресс хранится на устройстве; есть экспорт/импорт.
- **Аккаунты и турнир.** Регистрация по логину, паролю и коду приглашения; баллы за каждое верное
  задание; турнирная таблица за неделю (с понедельника); прогресс синхронизируется между устройствами.
- **Ударный режим:** серия дней подряд, календарь недели, заморозки ❄️ (за каждые 7 дней, максимум 2).
- **Защита контента:** уроки публикуются только зашифрованными (`enc/`, AES-256-GCM). Ключ выдаёт
  Supabase после входа и только участникам с кодом приглашения.

## Настройка Supabase (один раз)
1. Зарегистрироваться на https://supabase.com → **New project** (Free). Регион — любой ближайший.
2. `node tools/make_setup_sql.mjs` — соберёт `supabase/setup.local.sql` (схема + код приглашения + ключ).
   Открыть **SQL Editor → New query**, вставить содержимое файла, **Run**.
3. **Authentication → Sign In / Providers → Email**: выключить **Confirm email**, сохранить.
4. **Project Settings → API**: скопировать *Project URL* и *anon public* ключ в `config.js`.

Код приглашения — в `secrets.local.json` (`inviteCode`). Сменить его: поправить файл, снова
выполнить `node tools/make_setup_sql.mjs` и SQL. Часовой пояс недели — там же (`tz`).

## Запуск локально
```bash
tools/build.sh && python3 -m http.server 8765 --bind 127.0.0.1
```
Открыть http://localhost:8765. Вход и говорение работают только по HTTPS или на localhost,
поэтому на телефоне — через GitHub Pages.

## Структура
- `index.html`, `style.css`, `app.js` — приложение (без сборки и зависимостей).
- `data/index.json` — список уровней и уроков; `data/lessons/<ID>.json` — контент урока
  (открытые исходники, только локально; на GitHub — зашифрованная копия в `enc/`).
- `supabase/schema.sql` — таблицы и функции сервера (баллы, турнир, прогресс, выдача ключа).
- `config.js` — адрес Supabase и публичный anon-ключ.
- `tools/build.sh` — обновить индекс, проверить уроки, зашифровать. `node tools/encrypt.mjs --decrypt`
  восстанавливает `data/` из `enc/` (например, на новом компьютере).
- `tools/build_index.py` — сборка индекса и транскриптов; `tools/validate.py` — проверка уроков.
- `content_src/GENERATION_GUIDE.md` — как из транскрипта сделать урок.

## Добавить новые уроки (B1–C1)
1. Скачать автосубтитры: `yt-dlp --skip-download --write-auto-subs --sub-langs ru-orig --sub-format json3 ...`
2. `python3 tools/build_index.py <папка_плейлистов> <папка_субтитров>`
3. Сгенерировать `data/lessons/<ID>.json` по `content_src/GENERATION_GUIDE.md`, проверить `python3 tools/validate.py`.
4. `tools/build.sh` — обновит список уроков и зашифрует контент.
