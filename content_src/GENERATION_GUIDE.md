# Как сделать JSON урока из транскрипта

Вход: `content_src/transcripts/<ID>.txt` — автосубтитры (русская речь преподавателя + английские фразы).
Распознавание шумное: английские слова часто искажены («Point of viw», «hobes», «SH ass»). Восстанавливай правильный английский по смыслу.
Начало (приветствие, реклама приложения/соцсетей) и конец урока — пропускай.

Выход: `data/lessons/<ID>.json`. Образец формата и качества — `data/lessons/A1-01.json` (прочитай его целиком перед работой).

## Поля
- `id` — например "A1-07".
- `title` — короткая тема урока по-русски (до ~60 символов), конкретно: что за грамматика/лексика. Пример: "Present Simple: сложная лексика, work as, enjoy + -ing".
- `topics` — 4–8 коротких тегов.
- `theory` — 4–8 блоков `{h, text, ex: [[en, ru], ...]}`: конспект правил урока СВОИМИ словами, кратко и ясно, по-русски, с 1–3 примерами. Включай типичные ошибки, о которых говорит преподаватель.
- `vocab` — 15–30 слов/фраз урока `{en, ru}`.
- `sentences` — `{ru, en, alt?, src}`:
  - `src: "video"` — ВСЕ предложения-примеры, которые переводятся в уроке (обычно 20–45). Бери ровно ту фразу, что разбирается.
  - `src: "extra"` — новые предложения на ту же грамматику и лексику урока (минимум 30), чтобы было что тренировать. Разнообразь подлежащее (he/she/they/my friend/these people), отрицания и вопросы — если они есть в теме. Можно использовать лексику предыдущих уроков уровня. Не выходи за грамматику урока.
  - Итого `sentences` ≥ 60.
  - `en` — естественный, грамматически безупречный английский. Без лишней пунктуации в середине (запятые только где реально нужны).
  - `alt` — другие ПРАВИЛЬНЫЕ переводы, которые пользователь может ввести (порядок слов, синонимы, mom/mother, British/American spelling, «this/it»). Сокращения (don't / do not) добавлять НЕ нужно — приложение их понимает само. Числа можно цифрами (приложение не переводит цифры в слова — если число есть, добавь в alt вариант словами).
  - `ru` — естественный русский, с правильной пунктуацией.
- `gaps` — минимум 25 заданий с ОДНИМ пропуском `___`: `{en, ru, answer, alt?, options, explain}`. `answer` обязательно входит в `options` (3–4 варианта, уникальные, правдоподобные ошибки русскоязычных). `alt` — другие правильные ответы для ввода с клавиатуры. `explain` — одно предложение-правило по-русски. Для «без слова» используй вариант "—".
- `quiz` — минимум 10 вопросов `{q, options, answer (индекс), explain}`: выбор правильного предложения, поиск ошибки, значение фразы, выбор конструкции. Правильный ответ ставь на любой индекс (приложение перемешивает варианты).

## Проверка
`python3 tools/validate.py <ID>` должен показать ✓.
Пиши JSON аккуратно: двойные кавычки, без хвостовых запятых, кириллица как есть (не \u-escape).
